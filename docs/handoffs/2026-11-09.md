## Decisions & gotchas
- **Merges:** only on the owner's "merge", squash, `expectedHeadSha` pinned. Read sdd verdicts from the `checks` job log of a `pull_request_target` run of `sdd-checks.yml` whose head is the PR's head. Archive PRs: re-run `sdd-archive.sh verify` from a clean checkout of `main` with `npm ci --ignore-scripts`.
- **Lanes won't merge on a relayed "merge":** the owner has to say it in that lane's session. Verify a lane's claim of owner words with `list_events` (kinds user).
- **add_repo:** the classifier refused `push` access when it was asked for in order to merge. It allowed it for building a workflow the owner asked for. Public repos can be read without attaching them (`/home/user/<owner>/<repo>`).
- **Single-branch shallow clones** have no `origin/<branch>` after a push, so the stop hook says "no remote branch". Fix with `git fetch origin <b>:refs/remotes/origin/<b>`, add the fetch refspec, then `git branch -u`.
- **The session can't reach docs.npmjs.com.** npm's trusted-publishing details (OIDC before the token, 11.5.1 minimum) are from memory and wait to be proved by the second release.
- **Private → public:** garmin-map is private. webusb-mtp, garmin-mtp, osm-extracts and the blog are public. No private ADR text, secrets or internal hostnames go there; scan before each PR.
- **The publish credential lives in one job that runs no project code** (webusb-mtp ADR 0010). Keep that layout when copying the workflow to garmin-mtp.
- **Owner style:** short answers, ask once when something is ambiguous, merge then follow up rather than grow a PR. Report `/ci:minutes` and model spend at each merge (so far: webusb-mtp #4 7 minutes, #5 not yet measured; this session about $16.3).
